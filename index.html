Bonjour ! Je suis branché sur le portefeuille par six outils MCP : statistiques, recherche, fiche contrat, échéancier, simulation d'avenant et priorités de recouvrement. Posez une question, ou choisissez un exemple.

    Branchez votre propre agent

    Le même serveur MCP est public, en lecture seule. Dans Claude Code, par exemple :

    claude mcp add --transport http portefeuille https://…/api/mcp

    Architecture : interface HTML/CSS/JS sans framework → fonction serverless Node /api/assistant → Ministral 14B avec appels d'outils (boucle de 5 tours max) → six outils métier, les mêmes que ceux du serveur MCP /api/mcp (JSON-RPC 2.0, transport Streamable HTTP) et de sa version stdio. Aucune dépendance npm.
