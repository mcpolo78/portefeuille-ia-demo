Branchez votre propre agent

Les sept outils métier du portefeuille sont exposés par un serveur MCP public, en lecture seule. Le tableau de bord, les fiches et l'assistant passent tous par lui.

claude mcp add --transport http portefeuille https://…/api/mcp

    Architecture : interface HTML/CSS/JS sans framework, graphiques SVG faits main → fonctions serverless Node sur Vercel → /api/assistant (Ministral 14B avec appels d'outils, réponses en flux) et /api/mcp (JSON-RPC 2.0, Streamable HTTP, aussi en stdio). Aucune dépendance npm. Code source.
