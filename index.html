Bonjour ! Je suis branché sur le portefeuille par six outils MCP : statistiques, recherche, fiche contrat, échéancier, simulation d'avenant et priorités de recouvrement. Posez une question, ou choisissez un exemple. Cliquez sur un numéro de contrat pour ouvrir sa fiche.

Chaque outil appelé par le modèle : arguments, résultat brut et durée. Les chiffres de la réponse viennent de là, pas de l'imagination du modèle.

    Configurez sans code les règles de recouvrement. La première règle dont toutes les conditions sont vraies donne l'action et son niveau ; les poids calculent le score de priorité. L'assistant et le serveur MCP les appliquent aussitôt.

    Conditions possibles

    statut (sain, impayé, contentieux), produit (Crédit-bail, LOA, LLD, Crédit amortissable), partenaire, jours_retard_min, jours_retard_max, montant_impaye_min, encours_min. Niveaux : faible, moyen, élevé, critique. "si": {} est toujours vrai.

    Branchez votre propre agent

    Le même serveur MCP est public, en lecture seule. Dans Claude Code, par exemple :

    claude mcp add --transport http portefeuille https://…/api/mcp

    Architecture : interface HTML/CSS/JS sans framework → fonction serverless Node /api/assistant → Ministral 14B avec appels d'outils (boucle de 5 tours max) → six outils métier, les mêmes que ceux du serveur MCP /api/mcp (JSON-RPC 2.0, transport Streamable HTTP) et de sa version stdio. Aucune dépendance npm.
